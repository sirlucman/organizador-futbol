<ContentBand eyebrow="Why coaches switch" heading="Everything a matchday needs" columns={3}>

- Section headings are `--type-display-md` (40px / weight 900). Intro copy is `--type-body-lg` capped at 58ch.
- Feature grids run 2-up or 3-up on desktop, 1-up below 768px.
